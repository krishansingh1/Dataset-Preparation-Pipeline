# Dataset-Preparation-Pipeline

A small pipeline to generate a synthetic customer dataset and run a processing pipeline
that performs EDA, cleaning, feature engineering, splitting, and saves processed
splits and the preprocessing pipeline.

## Prerequisites
- Python 3.8+ (3.10+ recommended)
- Git/terminal access

## Quick Start

1. (Optional but recommended) Create and activate a virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

2. Install dependencies:

```bash
pip install numpy pandas scikit-learn pyarrow joblib
```

3. Generate the sample dataset (creates `customer_data.csv`):

```bash
python generate_dataset.py
```

4. Run the data pipeline (loads `customer_data.csv`, processes data, and writes outputs to `processed/`):

```bash
python data_pipeline.py
```

## What to expect
- `customer_data.csv` — generated by `generate_dataset.py` (sample dataset with intentional data issues).
- `processed/` — directory created by the pipeline. You should find:
	- `train.parquet`, `val.parquet`, `test.parquet` — processed splits saved as Parquet.
	- `preprocessor.pkl` — saved preprocessing `ColumnTransformer` for future use.

## Quick checks & troubleshooting
- After step 3: confirm `customer_data.csv` exists in the project root.
- After step 4: inspect the `processed/` directory for the Parquet files and `preprocessor.pkl`.
- If you get missing-package errors, re-run the `pip install` command above.

## Optional improvements
